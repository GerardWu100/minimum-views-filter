# Whitelists and Sync

## Always show a creator

**Fastest:** right-click a post or video → **Always show this creator**. The
toolbar icon flashes:

| Icon | Meaning |
|---|---|
| ✓ | Added, or already listed |
| ? | No creator found where you clicked |
| ! | Not saved: list too long, storage error, or that whitelist is switched off (hover the icon for details) |

Inside a card, this always adds the card's author, never a mentioned or quoted
account.

**Manual:** Settings → **X account whitelist** or **YouTube channel whitelist**,
one creator per line, then **Save**.

| Site | Accepted forms |
|---|---|
| X | `@NASA`, `NASA`, `https://x.com/NASA` |
| YouTube | `@NASA`, `https://www.youtube.com/@NASA`, `https://www.youtube.com/channel/UC...` |

Display names never match. A whitelisted creator skips the view minimum, the
unknown-count rule, and the X engagement rules.

## Sync

| Browser | Settings sync |
|---|---|
| Chrome | Across computers on the same Google account, with extension sync on |
| Firefox | Across computers on the same Firefox account |
| Brave | This computer only |

To copy settings between any two browsers: Settings → **Copy settings to another
browser** → **Copy**. In the other browser, paste into the same box →
**Load pasted** → check → **Save**.
