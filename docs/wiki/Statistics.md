# Statistics

Open the toolbar icon → **Statistics**. Everything stays in your browser's local
extension storage. It is never synced or uploaded.

| Tab | What it lists |
|---|---|
| **Hidden** | The latest 500 hidden items on both sites, with reason |
| **Kept by high engagement** | The latest 500 X posts the keep rule saved from hiding |
| **Highlighted** | The latest 500 X posts that met the highlight rule |

Each entry has a link, a short snippet or title, the counts at that moment, the
reason, and the time. Hide reasons:

| Reason | Meaning |
|---|---|
| Low views | Below that site's view minimum |
| Low likes/views | X likes below the minimum percentage |
| Unknown views | No readable count, with **Hide unknown view counts** on |

Totals count **events since reset**, not unique posts. A post that appears again
after a reload can count again. Kept and highlighted totals can overlap.

- **Reset statistics** clears all totals and lists.
- **Collect local statistics** (in Settings) pauses new events and keeps history.
- History never decides what is hidden.
